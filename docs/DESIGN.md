# Дизайн-спецификация

## Направление

Спокойный технологический стиль: **графитовый первый экран → белые и светло-серые разделы → один синий акцент**. Референс — мягкие светлые карточки с крупной типографикой и тёмными «пилюльными» кнопками. Отвергнутая альтернатива — полностью тёмная «хакерская» страница с неоном: для корпоративных клиентов (финансы, фарма, ретейл) она читается как стартап-игрушка и тяжело читается на длинных текстах.

Шрифт — **Manrope** (variable, кириллица), подключён через `@fontsource-variable/manrope`: самохостинг, без запросов к сторонним CDN (важно для РФ и конфиденциальности).

## Токены

Определены в `src/app/globals.css` (`@theme`). Контраст проверен по WCAG AA; axe-core на страницах — 0 нарушений.

| `graphite-900` | `#12161B` | первый экран, подвал | — |
| `graphite-800/700` | `#1D2229` / `#2B3139` | поверхности на тёмном | — |
| `fog-100` | `#EEF1F5` | светло-серые разделы | — |
| `fog-200/300` | `#E3E7EC` / `#C9D0D9` | границы, разделители | — |

Типографика: `h-hero` 32 → 56 px, `h-section` 30 → 48 px, `h-card` 20 px, основной текст 16 (телефон) / 17 px (десктоп). Межстрочный 1.6.

Сетка: контент до 1200 px (`.container-x`), 12 колонок, зазор 24 px, поля на телефоне 20 px. Отступ между разделами — 56 px на телефоне и 92–104 px на десктопе (по половине на каждую секцию).

Радиусы: карточки 24 px, изображения 16 px, кнопки и чипы — «пилюля». Тень карточки — одна мягкая (`--shadow-card`).

## Компоненты

- **Кнопки** (`.btn`): высота ≥ 48 px; `primary` (синяя), `dark` (графит), `secondary` (контур). Состояния: hover, active (сдвиг 1 px), focus-visible (контур 2 px, на тёмном — светлый), disabled (opacity .6 + `cursor:not-allowed`).
- **Шапка**: фиксированная, 64 px (телефон) / 72 px. На первом экране — полупрозрачный графит, после его прокрутки — белая с границей (переключает `IntersectionObserver`). На телефоне — меню-«шторка», `aria-expanded`, закрытие по Esc и по клику на пункт.
- **Карточки услуг/проектов/поставки**: изображение сверху (16:10 или 4:3), заголовок, текст, ссылка со стрелкой. На телефоне — по одной в колонке.
- **Форма**: поля ≥ 48 px, шрифт 16 px (iOS не зумит), направление — группа радио-«чипов», файл — зона с подписью, ошибки под полем + `aria-invalid`/`aria-describedby`, фокус на первом невалидном.
- **FAQ**: нативный `<details name="faq">` — без JS, клавиатура и скринридеры работают из коробки.
- **Схема ИИ (IMG-05)**: HTML + inline SVG, текст живой; три шага в ряд от 1280 px, ниже — вертикально.

## Состояния, о которых обычно забывают

- Форма: пусто / ошибка поля / отправка / **не подключена** / ошибка доставки / успех / файл не доставлен (частичный успех).
- Скрытые данные: характеристики без подтверждения показывают подсказку, а не пустую ячейку; раздел «Проекты» скрыт целиком, пока нет подтверждённых кейсов.
- Самая узкая ширина — 320 px: проверено на отсутствие горизонтальной прокрутки (390, 768, 1024, 1280, 1440 — тоже).
- Движение: появление блоков при прокрутке — чистый CSS (`animation-timeline: view()`), отключается при `prefers-reduced-motion` и в печати; без поддержки браузера контент просто виден.
