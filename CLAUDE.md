# H200 Cloud — лендинг (Next.js)

Адаптивный лендинг рабочего названия **H200 Cloud**: аренда GPU-серверов для ИИ, поставка оборудования из Китая, настройка и сопровождение. Цель сайта — портфолио компании и обращения от корпоративных клиентов.

## Агенты проекта (`.claude/agents/`)

| Агент | Роль | Когда вызывать |
|---|---|---|
| **Лютик** (`lyutik`) | Frontend: React 19, Next.js 15, TypeScript. Объясняет решения. | **Сейчас ведёт разработку.** «Лютик», `/frontend`, любая правка интерфейса |
| **Джобс** (`jobs`) | UI/UX: токены, спецификации компонентов. Пишет спеки, не React. | Новая секция, изменение визуала, аудит дизайн-системы |
| **Геральт** (`geralt`) | Backend: NestJS/Python/Postgres/Redis. Без лишних слов. | Если появится отдельный бэкенд (CRM, очередь заявок, БД) |

Агенты подхватываются при старте новой сессии Claude Code в этом репозитории.

## Правила контента (важно)

Из исходных материалов подтверждено только то, что есть в ТЗ. **Не публиковать без подтверждения компании:** количество клиентов/оборудования/площадок, загрузку и доступность мощностей, сравнение цен, выручку и доходность, логотипы и названия клиентов, гарантированные сроки и режим поддержки (в т. ч. «24/7»), модели GPU и характеристики серверов.

Все такие факты лежат в `src/content/site.ts` и **выключены по умолчанию**. Чек-лист — `docs/CONTENT-TODO.md`. Вымышленных кейсов, сотрудников и показателей быть не должно.

Изображения — собственные иллюстрации/визуализации (реальных фото нет); они не выдаются за фото компании. Реестр — `docs/IMAGES.md`.

## Демо-режим

`NEXT_PUBLIC_DEMO=1` (в сборке для Pages по умолчанию) выводит все скрытые блоки: шаблоны проектов, карту площадок, карточки специалистов, реквизиты и контакты-заглушки. Это только для показа: заглушки в `[скобках]`, сайт с `noindex`. Боевая сборка — `DEMO=0`. Не переносить демо-данные в `src/content/site.ts` как «реальные».

## Команды

```bash
npm run dev        # разработка
npm run build      # прод-сборка (включает проверку типов и линт)
npm run typecheck  # tsc --noEmit
npm run lint
npm run build:pages # статика для GitHub Pages (DEMO=1 по умолчанию — показывает все блоки)
npm run images     # пересобрать 18 изображений, src/content/images.generated.ts и docs/IMAGES.md
```

## Соглашения

- Server Components по умолчанию; `'use client'` только там, где нужны состояние/обработчики: `Header`, `DirectionLink`, `LeadForm`.
- Стили: Tailwind v4, токены — в `@theme` в `src/app/globals.css` (спецификация — `docs/DESIGN.md`). Одноразовых hex-цветов в компонентах нет.
- Типы честные: без `any`, `as` и `@ts-ignore`. Состояние отправки формы — discriminated union.
- Секции светлых тонов чередуются белый/серый автоматически в `src/app/page.tsx` (скрытый раздел не ломает чередование).
- Изображения подключаются через `<Illustration id="img-XX" />`; не вставлять `<img>` вручную.
